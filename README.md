## 📌 Introduction

This project is a personal portfolio website developed as part of the Web Engineering Lab assignment. It serves as a digital CV to present my educational background, technical skills, projects, experience, certifications, and contact information in a professional and organized manner.

The website is designed to provide visitors with a clear overview of my academic journey, development skills, and projects.

## 🎯 Objectives

- Create a personal digital CV using HTML, CSS, and Bootstrap.
- Present academic qualifications and technical skills.
- Showcase at least three projects.
- Display experience and certifications.
- Provide contact information and social media links.
- Ensure responsiveness across mobile, tablet, and desktop devices.

## 🛠️ Technologies Used

- **HTML5** — Website structure and content.
- **CSS3** — Styling and layout customization.
- **Bootstrap 5** — Responsive design and reusable components.
- **Bootstrap Icons** — Icons for navigation, contact information, and social links.
- **JavaScript** — Interactive features, where applicable.
- **Git and GitHub** — Version control and project hosting.
- **GitHub Pages** — Website deployment.

## 📂 Website Sections

1. **Navbar** — Navigation links to the main sections.
2. **Home** — Introduction and welcome section.
3. **About Me** — Personal introduction and career interests.
4. **Education** — Academic qualifications.
5. **Skills** — Programming languages, web technologies, and development tools.
6. **Projects** — Three or more projects showcasing practical work.
7. **Experience / Certifications** — Relevant experience and certificates.
8. **Contact** — Contact details and social media links.
9. **Footer** — Copyright information and social links.

## 📱 Responsive Design

The website uses Bootstrap's responsive grid system and layout utilities to adapt to different screen sizes, including:

- Mobile phones
- Tablets
- Desktop and laptop screens

Responsiveness should be tested on different viewport sizes before submission.
